## 연락 규칙 / Contact rule — 어디로, 몇 시간 내 응답
카카오톡, Slack, Notion 사용
- 간단한 연락은 카카오톡으로 진행하며, 프로젝트(업무) 기록은 Slack에 기록함.
- 2시간 내 답장을 지키기로 노력하며, 2시간 이후 답장 시 사유를 남겨야 함.
- 답장할 때 해당 일에 대한 마감기한을 첨부하기.(e.g. m월d일 n시까지 해두겠습니다!)


## 회의 규칙 / Meeting rule — 요일·시간·불참 처리
- 매주 화요일 or 수요일 19:00
- 불참 사유 발생 시, 최소 하루 전에는 팀원에게 공유할 것


## 기여 규칙 / Contribution rule — 1인당 주 최소 작업량
- 타 팀원의 PR에 대한 코드리뷰 1건 이상 진행하기
- 매주 정기회의 하루 전까지 Notion, Slack에 개별 진행상황(진행도, 에러, 해결과정) 문서화 및 업데이트


## 갈등 처리 / Conflict rule — 의견이 갈릴 때
- 각 주장에 대한 간단한 프로토타입이나 레퍼런스 등을 검토하여 객관적으로 비교한 후 다수결로 결정한다.
- 서로의 의견을 존중하며 감정적으로 대하지 않기
- 회피형으로 일방적 연락두절 금지(연락규칙 2번)
- 화났을 시 **용용체** 사용


## 마감 규칙 / Deadline rule
- 정해진 마감 기한에서 최소 48시간 이전에 내부 마감을 진행하고, 제출 하루 전 다같이 검토 후 제출한다.
- 할당된 이슈를 기한 내에 완료하지 못할 것 같다면, 내부 마감기한 하루 전에 카카오톡에 현재 상황, 지연 예상 시간을 공유하고 도움을 청한다.



## **팀 공용 언어 / Working language** — 회의 언어 / 기록 언어
- 변수명은 영어 소문자로 사용, 그 다음단어는 첫단어만 대문자로 명시
- 커밋 컨벤션
  feat : 새로운 기능 추가
  fix : 버그 수정
  docs : 문서 수정
  style : 코드 포맷팅, 세미콜론 누락, 코드 변경이 없는 경우
  refactor : 코드 리펙토링
  test : 테스트 코드, 리펙토링 테스트 코드 추가
  chore : 빌드 업무 수정, 패키지 매니저 수정
  
- 회의 언어: 한국어
- 기록 언어(커밋메시지 포함): 한국어, 영어 혼용


## AI 사용에 대한 팀 합의 / Team agreement on AI use
- 프로토타입 초안, 테스트 코드 초안 작성 및 알고리즘 로직 추천 등의 용도로 사용할 것.
- AI가 생성한 코드를 프로젝트에 반영할 경우, 해당 팀원은 그 코드의 작동 원리를 100% 이해하고 팀원에게 사전에 설명할 수 있어야 함.
설명하지 못한다면 롤백.
- API Key, 개인정보, 민감한 데이터 등은 프롬프트에 입력하지 않을 것.


## 성찰 / Reflection — 가장 걱정되는 것
강수연: 역할 분담을 잘했다고 생각했는데, 막상 프로젝트 시작할 때 역할 분담이 애매하게 되어있어서 진행이 더딜까봐 걱정돼요.
김용태: 어떤 프로젝트를 진행할지 아직 모르겠고, 내가 작성한 코드가 문제를 큰 일으킬까봐 걱정된다.
송선우: 정확히 이 팀에서 무슨 작업을 맡아야 될지 아직 모르는 것, 협업 과정에서 기술 에러가 발생했을 때 대처해야할 미래가 걱정된다.
이재림: 프로젝트 진행 중 충돌이 발생했을 때, 이 문제를 유연하게 잘 해결할 수 있을지에 대한 걱정.
