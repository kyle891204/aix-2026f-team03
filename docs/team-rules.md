# 팀 규칙 / Team Rules

1주차 활동지(week-01.md)에서 합의한 내용을 여기에 정리합니다.
*Copy the agreements from week-01.md here.*

1.**연락규칙**: 간단한 연락은 카카오톡으로, 프로젝트 업무 기록은 Slack과 Notion으로 진행.  
2시간 내 응답을 원칙으로 하며, 2시간 이후 답장 시 사유를 남긴다.  
프로젝트 업무에 대한 답장 시, 업무에 대한 마감 기한을 반드시 함께 작성한다.

2.**회의규칙**: 정기 회의는 매주 화요일 또는 수요일 19시에 진행한다.  
불참 사유가 발생할 경우, 최소 하루 전에는 팀원에게 미리 공유한다.

3.**기여처리**: 타 팀원의 PR에 대해 1건 이상 코드 리뷰를 진행한다.  
정기회의 하루 전까지 Notion과 Slack에 개별 진행 상황(진행도, 에러, 해결 과정)을 문서화하여 업데이트한다.

4.**갈등처리**: 의견이 갈릴 경우, 각 주장의 프로토타입이나 레퍼런스를 객관적으로 검토한 후 다수결로 결정한다.  
서로 존중하며 감정적인 대처나 회피성 연락 두절은 금지한다.  
화났을 경우 **"용용체"**를 사용한다.

5.**마감규칙**: 공식 마감 기한 최소 48시간 전 내부 마감을 진행하고, 제출 하루 전에 팀원 다 같이 검토 후 최종 제출한다.  
할당된 이슈를 기한 내 완료하지 못할 것 같다면, 내부 마감 기한 하루 전 카카오톡을 통해 현재 상황과 지연 예상 시간을 공유하고 도움을 청한다.

6.**팀 공용언어**: 회의 언어는 한국어로 사용하고, 기록 언어(커밋 메시지 포함)는 한국어와 영어를 혼용한다.  
변수명은 영어 소문자로 시작하되, 다음 언어의 첫 글자만 대문자로 명시한다.(카멜케이스).  
합의된 커밋 컨벤션(feat, fix, docs, style, refactor, test, chore)을 준수한다.

7.**AI사용원칙**: AI는 프로토타입이나 테스트 코드 초안 작성, 알고리즘 로직 추천 용도로 제한하여 사용한다.  
AI가 생성한 코드는 100% 원리를 이해하고 팀원에게 사전 설명할 수 있어야 하며, 설명하지 못할 경우 롤백한다.  
API Key, 개인정보 등 민감한 데이터는 프롬프트에 **절대** 입력하지 않는다.
