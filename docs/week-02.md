## 4. 두 조의 결과 비교

작업이 끝나면 두 조가 만든 코드를 나란히 놓고 함께 답하세요.

**4-1. 두 결과의 가장 큰 차이는 무엇입니까?**

```
A조의 결과는 전체적으로 HTML을 기반으로, 브라우저의 localStorage에 저장된 메모를 활용하며, UI가 존재하는 독립실행 프론트엔드 앱이다.
반면 B조의 결과는 이미 틀이 갖춰져있는 서버-DB 구조에 HTTP 요청을 보내서 서버가 DB를 조회하는, 특별한 UI가 존재하지 않는 백엔드 앱이라는 차이가 있다.
```

**4-2. A조의 실패는 모델 탓입니까, 우리가 주지 않은 탓입니까? 근거를 들어 적으세요.**

```
우리가 주지 않은 탓이라고 생각한다. 우리가 원하는 요구사항을 정확하게 기록하지 않았기 때문에, 어떠한 사항을 위반하였는지 알 수 없고, 어떤 항목/기능을 생성해야하는지 AI가 스스로 판단해야했기 때문에 우리의 정확한 요구사항을 알 수 없었기 때문이다.
```

**4-3. B조가 준 자료 중 결과를 가장 크게 바꾼 것 하나를 꼽는다면 무엇입니까? 왜 그렇게 생각합니까?**

```
CONVENTIONS.md라는 규약 md 파일을 준 것이 결과를 가장 크게 바꿨다고 생각한다. 그 이유는 특별한 요구사항과 규칙을 알려준 상태로 코드를 수정하게 하여 예상하지 못했던 상황에서의 버그가 일어나지 않게끔 대비했기 때문이다. 예를 들어, '모든 쿼리에 user_id 조건을 포함한다'는 규칙이 있었기 때문에 기존 코드에 없던 새로운 상황에서의 버그를 방지할 수 있었다.
```
